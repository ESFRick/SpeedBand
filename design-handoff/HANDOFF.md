# SpeedBand · Pulse Redesign — Handoff to Claude Code

> Полный пакет для интеграции концепции **Pulse** в твой Go-проект `SpeedBand` (`internal/webui/static/`).
> Цель: заменить HTML + CSS на дизайн Pulse, **не трогая** `app.js` и серверную часть.

---

## 1. Что такое Claude Code и как им пользоваться

**Claude Code** — это CLI-инструмент от Anthropic, который запускается в терминале и работает с твоим
кодом напрямую (читает файлы, делает правки, запускает команды). Это **тот же Claude**, но с доступом к
файловой системе и `git`. Для интеграции дизайна это идеальный сценарий.

### Установка (5 минут)

```bash
# 1. Установи Claude Code (Node 18+)
npm install -g @anthropic-ai/claude-code

# 2. Зайди в свой проект
cd /path/to/SpeedBand

# 3. Запусти его
claude
```

При первом запуске он попросит авторизоваться (откроется браузер с Anthropic). Дальше — обычный
терминальный диалог: ты пишешь, что хочешь, он читает код, предлагает правки, ждёт твоего `y`/`n`.

### Как мы это используем

Ты делаешь так:

1. Скачиваешь этот пакет (см. кнопку «Download» в этом проекте — она отдаёт всю папку zip-ом).
2. Кладёшь содержимое архива в `SpeedBand/design-handoff/` (или куда угодно — главное, чтобы Claude
   Code мог это прочитать).
3. Запускаешь `claude` в корне репозитория.
4. Вставляешь готовый промт (раздел **5** этого документа).
5. Claude Code откроет `design-handoff/HANDOFF.md`, `concept-pulse.jsx`, `data.jsx`, прочитает
   текущий `internal/webui/static/index.html`, `styles.css`, `app.js` — и сделает правки **по плану из
   раздела 3**.

## 2. Что меняется и что остаётся

### ✅ Остаётся как есть

- **`internal/webui/static/app.js`** — вся логика тестов, чарт на `<canvas>`, i18n, обработчики кнопок.
  Мы намеренно сохраняем все `id` и `data-*` атрибуты, чтобы этот файл не пришлось трогать.
- **Серверная часть** (`internal/server/`, `internal/tests/`, `internal/metrics/`) — без изменений.
- **`internal/webui/embed.go`** — без изменений (он просто embed-ит `static/`).
- **API-эндпоинты, WebSocket, формат JSON-отчётов** — без изменений.

### 🎨 Меняется

- **`internal/webui/static/index.html`** — переписывается на Pulse-разметку: новая шапка, гауге-герой,
  карточки метрик с иконками и спарклайнами, цветные бары лестницы, премиальные кнопки.
- **`internal/webui/static/styles.css`** — переписывается с нуля под Pulse: новая палитра,
  `Plus Jakarta Sans`, переменные градиента, glass-карточки, focus/hover-состояния.
- **(Опционально) добавляется** `internal/webui/static/pulse-extras.js` — рендерит SVG-гауге и
  спарклайны (мелкие графики в карточках метрик), которым `app.js` передаёт значения. Без этого
  файла кружок-гауге показывается как обычное большое число — `app.js` обновляет его так же.

## 3. Контракт DOM-узлов (КРИТИЧНО)

`app.js` обращается к DOM по `id` и нескольким `data-*` атрибутам. **Все они должны остаться** в новом
HTML, иначе тестирование сломается. Вот полный список:

### По `id` (через `document.getElementById`)

| id | Используется для |
| --- | --- |
| `serverStatus` | пилл «Локальный сервер: онлайн» в шапке |
| `clientStatus` | пилл «Клиент: браузер» |
| `copyUrlButton` | кнопка «Скопировать URL сервера» |
| `samePcWarning` | жёлтая полоса-предупреждение (gated `.hidden`) |
| `heroValue` | главное число героя («Готово» / «238 Mbps») |
| `stageText` | подпись под заголовком героя |
| `presetSelect` | `<select>` сценария |
| `startButton`, `quickButton`, `fullButton`, `advancedButton`, `stopButton` | кнопки запуска |
| `advancedPanel` | панель «продвинутых параметров» (показывается toggleом) |
| `latencySamplesInput`, `downloadDurationInput`, `uploadSizeInput`, `ladderDurationInput` | `<input type="number">` внутри панели |
| `downloadValue` … `stabilityValue` (×6) | большие числа в карточках метрик |
| `downloadStatus` … `stabilityStatus` (×6) | подписи под числами (`Не проверено`, `Отлично`, …) |
| `protocolNote` | бейдж «Realtime: WebSocket fallback» |
| `ladderBody` | `<tbody>` таблицы лестницы — `app.js` ВСТАВЛЯЕТ строки сам |
| `verySafeValue`, `recommendedValue`, `riskyValue`, `avoidValue` | значения в карточках рекомендаций |
| `whyList` | `<ul>` с пунктами «почему» |
| `copyReportButton`, `downloadJsonButton`, `saveReportButton`, `detailsButton` | кнопки отчёта |
| `reportSaveStatus` | статус-строка под кнопками («Сохранено», «Ошибка», …) |
| `reportText` | `<pre>` с текстом отчёта |
| `technicalDetails` | `<pre>` с подробным JSON (gated `.hidden`) |
| `chartSubtitle` | подпись над чартом |
| `throughputChart` | `<canvas>` чарта — **должен остаться `<canvas>`**, не SVG. `app.js` рисует туда сам. |

### По `data-*` атрибутам

| атрибут | где | что делает |
| --- | --- | --- |
| `data-language="en"` / `data-language="ru"` | кнопки переключения языка | `app.js` слушает клики и перерисовывает i18n |
| `data-chart-mode="all" / "http" / "realtime"` | кнопки переключения режима графика | `app.js` обновляет canvas |
| `data-i18n="key"` | любые текстовые элементы | `app.js` подставляет перевод по словарю |
| `data-i18n-attr="aria-label:aria.metrics"` | элементы с aria-label | `app.js` переводит атрибут |

> ⚠️ **Главное правило:** если в твоём новом HTML есть текст из существующего i18n-словаря, обязательно
> поставь `data-i18n="key"`. Иначе при переключении языка он не переведётся. Список ключей —
> в `app.js` (объект `translations`).

## 6. Чек-лист после интеграции

Перед тем как закоммитить, прогони руками:

- [ ] `Локальный сервер: онлайн` пилл показывается в шапке.
- [ ] Кнопка «Скопировать URL сервера» работает (тост или копирование).
- [ ] Переключение EN/RU перерисовывает все тексты.
- [ ] Селект сценария меняет текущий preset.
- [ ] «Запустить калибровку» запускает реальный тест — чарт растёт, числа метрик меняются.
- [ ] «Остановить» появляется во время теста и прерывает его.
- [ ] Жёлтое предупреждение про loopback показывается, когда сервер и клиент на одном IP.
- [ ] Таблица лестницы заполняется строками — статусы цветные (зелёный/жёлтый/красный).
- [ ] Карточки «Очень безопасно / Рекомендуется / …» получают значения после полного теста.
- [ ] Кнопки отчёта работают: «Скопировать», «Скачать JSON», «Сохранить на сервере», «Тех. детали».
- [ ] Канвас чарта не пустой, в нём 3 серии (DL/UL/Target) и работает переключение режима All/HTTP/Realtime.

Если что-то сломалось — открой DevTools, посмотри ошибки. Скорее всего, потерян `id` из таблицы
раздела 3. Скажи Claude Code: «id `X` потерялся, верни его на правильный элемент».

## 7. Что дальше (необязательно)

- **Перенос на Tailwind или CSS-модули** — если хочешь современный стек, скажи Claude Code:
  «преобразуй styles.css в Tailwind-классы прямо в index.html, удали styles.css».
- **Аниматор gauge** — `requestAnimationFrame`-tween от старого значения к новому при апдейте
  `downloadValue` (Claude Code справится за один промт).
- **Темизация через CSS-переменные** — выведи градиент в `--pulse-grad-a/b/c` и дай пользователю
  выбор палитры в настройках (как в Tweaks-панели прототипа).
- **Сохранение последнего отчёта в localStorage** — чтобы открытие пустой страницы не показывало
  «—», а сразу подгружало прошлый прогон.

Удачи с интеграцией. Если что-то непонятно — пиши, доточим.
