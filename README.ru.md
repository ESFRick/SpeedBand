## Что делает SpeedBand

Запускает небольшой HTTP-сервер на вашем компьютере. Другое устройство открывает страницу в браузере и последовательно выполняет тесты:

1. Задержка и джиттер (`/api/ping`)
2. Скорость загрузки по HTTP (`/api/download`)
3. Скорость отдачи по HTTP (`/api/upload`)
4. Ступенчатая лестница битрейтов через WebSocket (`/api/ws`)

Весь трафик остаётся внутри сети. Результаты включают стабильный диапазон битрейта с уровнями запаса, оценку качества и разбивку по ступеням лестницы.

**Пиковая скорость - не безопасный битрейт для стриминга.** SpeedBand использует низкопроцентильную пропускную способность, джиттер и обнаружение зависаний, чтобы оценить безопасный рабочий диапазон.

---

## Почему не iperf3?

iperf3 требует установки на оба устройства и показывает сырую TCP-пропускную способность - не то, что реально важно для стриминга.

SpeedBand запускается одним бинарником или через `go run`. На втором устройстве нужен только браузер. Инструмент измеряет именно то, что используют стриминг-приложения: низкопроцентильную пропускную способность, джиттер, зависания и стабильность битрейта по ступенчатой лестнице. На выходе - безопасный диапазон с уровнями запаса, а не просто пиковое число.

## Быстрый старт

**Windows (PowerShell):**

```powershell
go run ./cmd/speedband
```

**Linux / macOS:**

```bash
go run ./cmd/speedband
```

Сборка бинарника:

**Windows:**

```powershell
go build -o speedband.exe ./cmd/speedband
# или
.\scripts\build-windows.ps1
```

**Linux / macOS:**

```bash
go build -o speedband ./cmd/speedband
# или
bash scripts/build.sh
```

Откройте LAN-адрес из консоли на любом устройстве в той же сети. На втором устройстве ничего устанавливать не нужно - только браузер.

### Флаги

| Флаг | По умолчанию | Описание |
|------|-------------|----------|
| `--host` | `0.0.0.0` | Адрес для прослушивания |
| `--port` | `8080` | Порт |
| `--open` | `false` | Открыть браузер при запуске |
| `--debug` | `false` | Подробное логирование |

## Подключение с другого устройства

1. Запустите SpeedBand на основном компьютере.
2. Откройте LAN-адрес из консоли на другом устройстве, например `http://192.168.1.25:8080`.
3. Если `.local`-адрес не открывается, используйте числовой IP.
4. На Meta Quest откройте адрес в браузере гарнитуры.

Консоль выводит все найденные LAN-адреса и помечает наиболее вероятный. Адаптеры Docker, VM и VPN фильтруются или отмечаются отдельно.

## Брандмауэр

Если страница не открывается с другого устройства:

- Убедитесь, что оба устройства в одной подсети.
- **Windows:** при запросе разрешите доступ в **частных сетях**. Если запроса не было - разрешите `speedband.exe` или `go.exe` в брандмауэре Windows для частных сетей.
- **Linux:** откройте порт (`sudo ufw allow 8080/tcp` для дистрибутивов с UFW).
- **macOS:** разрешите входящие подключения при запросе системного брандмауэра.
- Попробуйте числовой IP вместо `.local`.
- Временно отключите VPN.

SpeedBand по умолчанию слушает `0.0.0.0`. Запускайте только в доверенной локальной сети.

## Чтение результатов

Уровни диапазона битрейта:

| Уровень | Что означает |
|---------|-------------|
| Очень безопасный | Консервативная оценка с хорошим запасом |
| Рекомендуемый | Стабильный рабочий диапазон |
| Рискованный верхний | Может работать, но с меньшим запасом или со всплесками |
| Не рекомендуется | Без проверки в реальном приложении лучше не использовать |

Метки качества:

| Метка | Что означает |
|-------|-------------|
| Отлично | Высокая низкопроцентильная пропускная способность, низкий джиттер |
| Хорошо | Подходит для большинства задач реального времени |
| Приемлемо | Работает, но оставляйте запас |
| Рискованно | Нестабильно, нужна осторожность |
| Нестабильно | Не подходит для стриминга с высоким битрейтом |

## Отчёты

- **Скачать JSON** - сохраняет отчёт на клиентском устройстве.
- **Сохранить на сервер** - отправляет отчёт на основной компьютер; сохраняет `.log`-файл в папке `reports/` в рабочем каталоге сервера.

Интерфейс поддерживает русский и английский. Отчёт сохраняется на том языке, который выбран в браузере.

## Рекомендации по тестированию

- Подключите основной компьютер к роутеру по Ethernet.
- Используйте Wi-Fi 5 ГГц или 6 ГГц для второго устройства.
- Закройте активные загрузки, облачную синхронизацию и обновления игр.
- Перед выбором высокого битрейта запустите полный тест стабильности.
- Повторите 2–3 раза и ориентируйтесь на более консервативный результат.
